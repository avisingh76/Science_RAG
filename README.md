# 🔬 Science RAG — Agentic RAG Assistant

An agentic Retrieval-Augmented Generation (RAG) assistant for science textbooks. Upload any PDF, ask questions, and get accurate answers with page citations — powered by LangGraph, Sentence Transformers, and OpenRouter.

---

## ✨ Features

- **Multi-PDF Support** — Upload and search across multiple textbooks simultaneously
- **Hybrid Search** — Combines semantic search (FAISS) + keyword search (BM25) for better results
- **Reranking** — CrossEncoder reranks results for highest answer quality
- **Agentic Pipeline** — LangGraph agent decides which tools to call (RAG, SQL, Wikipedia)
- **User Accounts** — JWT-based authentication with register/login
- **Admin Dashboard** — Manage users, sessions, and books from a dedicated UI
- **Session History** — Conversations are saved and resumable
- **Wikipedia Augmentation** — Real-world context added alongside textbook answers

## 🚀 Local Setup

### 1. Clone the repo
```bash
git clone https://github.com/your-username/science-rag.git
cd science-rag
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
pip install "pydantic[email]" "python-jose[cryptography]" "passlib[bcrypt]" argon2-cffi rank-bm25 slowapi tenacity sqlparse aiosqlite asyncpg
```

### 3. Create `.env` file
```env
OPENROUTER_API_KEY=your_openrouter_key
OPENROUTER_MODEL=openai/gpt-4o-mini
APP_API_KEY=your_secret_admin_key
JWT_SECRET=your_jwt_secret
JWT_EXPIRE_MINUTES=1440
DATABASE_URL=sqlite+aiosqlite:///./data/metadata.db
ALLOWED_ORIGINS=http://localhost:8501
API_URL=http://localhost:8000
ENABLE_RERANKING=true
```

Generate secret keys:
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### 4. Add your PDF
Place PDF files in `data/pdfs/` folder.

### 5. Run ingestion
```bash
python -m pipeline.ingest
```

### 6. Start the backend
```bash
uvicorn api.main:app --reload --port 8000
```

### 7. Start the frontend
```bash
# Chat UI
streamlit run ui/app.py

# Admin dashboard (separate terminal)
streamlit run ui/admin.py --server.port 8502
```

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Health check |

## 🚢 Deploy on Railway

See [DEPLOY.md](DEPLOY.md) for full deployment guide.

**Quick steps:**
1. Push repo to GitHub
2. Create Railway project → Add PostgreSQL
3. Deploy FastAPI service — set env vars
4. Deploy Streamlit service — set `API_URL`
5. Upload PDFs via `/ingest` endpoint

**Required env vars on Railway:**

| Variable | Service |
|---|---|
| `OPENROUTER_API_KEY` | Backend |
| `APP_API_KEY` | Backend + Frontend |
| `JWT_SECRET` | Backend |
| `DATABASE_URL` | Backend (auto from Railway PostgreSQL) |
| `ALLOWED_ORIGINS` | Backend |
| `API_URL` | Frontend |
| `ENABLE_RERANKING` | Backend (`false` for free tier) |

## 🔒 Security

- Passwords hashed with Argon2
- JWT tokens with configurable expiry
- SQL injection protection via sqlparse + table whitelist
- CORS restricted to specific origins
- Rate limiting on `/chat` (10 requests/minute)
- Admin endpoints protected by separate API key
